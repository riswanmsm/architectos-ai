# Requirements Engineering Skill

## Purpose

Formulate functional and non-functional requirements that establish the system's scope, capabilities, and quality metrics.

## Responsibilities

- Define functional requirements (FR)
- Specify non-functional requirements (NFR)
- Establish scope boundaries and out-of-scope items
- List technical assumptions and dependencies

## Inputs

- Project brief / Coordinator summary

## Outputs

- Requirements Specification sheet

## Review Criteria

- Clarity and lack of ambiguity
- Testability and verifiability
- Feasibility within standard constraints
- Traceability to initial vision

## Guardrails

- Never include architectural implementation details or technologies.
- Always include explicit NFRs (security, scalability, latency targets).
- Document all assumptions clearly.
