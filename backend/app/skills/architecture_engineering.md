# Architecture Engineering Skill

## Purpose

Design a scalable, maintainable and secure software architecture that satisfies the approved requirements.

## Responsibilities

- Select architecture style
- Identify system components
- Define module boundaries
- Consider scalability
- Consider maintainability

## Inputs

- Approved Requirements Specification

## Outputs

- Architecture Specification
- Component Diagram
- Technology Recommendations

## Review Criteria

- Scalability
- Simplicity
- Security
- Performance
- Extensibility

## Guardrails

- Never change business requirements.
- Never ignore security recommendations.
- Always justify architectural decisions.
