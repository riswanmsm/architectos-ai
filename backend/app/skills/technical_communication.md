# Technical Communication Skill

## Purpose

Format, align, and compile the unified specification blueprint package for developer handoff.

## Responsibilities

- Standardize markdown formats and styles
- Ensure consistency between schemas, API specs, and requirements
- Build final executive summary and file checklist
- Verify blueprint package readability

## Inputs

- Audited & Approved Engineering Blueprint files

## Outputs

- Final Engineering Blueprint Package
- Handoff Documentation

## Review Criteria

- Package completeness
- Layout consistency
- Text readability and spelling
- Technical clarity

## Guardrails

- Never modify structural data or architecture patterns.
- Preserve all security audit findings and warnings.
- Maintain a strict professional engineering tone.
